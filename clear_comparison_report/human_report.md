## Notes

- For variance relaxation there is no mathematically sharp true start, because the variance relaxes exponentially. The script therefore reports a configurable nominal start: by default, the first index where the constructed variance is within 10% of equilibrium.
- `MDTest start` is the Schiferl--Wallace/MDTest stationarity-admissible start (`selected_start_index_sw`).
- `Max start` is the conservative start used by `auto-compare`, i.e. `max(MDTest start, ESS start)`. This is useful for a combined workflow, but it should not be confused with a pure stationarity diagnostic.
